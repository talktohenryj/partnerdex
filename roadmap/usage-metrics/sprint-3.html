Sprint 3 — Usage metric definitions

Not started · repo: partnerdex · migration 5

Why this ships now

Raw events answer "what happened". Henry wants named numbers: Total Revenue, Total Orders, Upsell Revenue, GC Dollars Redeemed. Mantle does this with a definition — name, event, count or sum of a property. Without that layer, every number is still a hand-written query.

Why this is independently deployable

New table and new routes only. The customer page does not read definitions until S4. The settings page has its own preview, so a definition is useful the day it is saved: pick a customer and a window, see the number.

Build

  1. Migration 5 — src/db/migrate.ts 
    CREATE TABLE IF NOT EXISTS usage_metrics (
  id               TEXT PRIMARY KEY,          -- crypto.randomUUID()
  app_id           TEXT NOT NULL,
  name             TEXT NOT NULL,
  event_name       TEXT NOT NULL,
  method           TEXT NOT NULL CHECK (method IN ('count','sum')),
  property         TEXT,                      -- required when method='sum'
  filters          TEXT NOT NULL DEFAULT '[]',-- reserved: [{property, op:'eq', value}]
  show_on_customer INTEGER NOT NULL DEFAULT 1,
  format           TEXT NOT NULL DEFAULT 'number' CHECK (format IN ('number','usd')),
  position         INTEGER NOT NULL DEFAULT 0,
  created_at       TEXT NOT NULL,
  updated_at       TEXT NOT NULL,
  UNIQUE (app_id, name)
);
    format exists because PartnerDex does not know that usdOrderTotal is money; Henry marks it.
  2. Aggregator — src/usage/compute.ts (new) aggregateMetric(metric, { shopId?: string, from: string, to: string }, db): number. 
    SELECT {method = count ? COUNT(*) : COALESCE(SUM(CAST(json_extract(properties, @path) AS REAL)), 0)}
  FROM usage_events
 WHERE app_id = @appId AND event_name = @eventName
   AND occurred_at >= @from AND occurred_at < @to
   [AND shop_id = @shopId]
    @path = '$."' + property + '"' (quoted, so camelCase and dots are safe); property validated against /^[A-Za-z0-9_]{1,64}$/ at save. One function — S4 and S5 call it, nothing else re-implements the sum.
  3. Windows — src/usage/windows.ts (new) resolveUsageWindow(key, now, timezone) for 24h, 7d, 30d, 90d, 365d, mtd, all → {from, to} ISO. Month-to-date uses REPORTING_TIMEZONE through the helpers in src/metrics/time.ts, so "this month" means the same thing as on the revenue page. Mantle's "current billing period" is dropped: PartnerDex would need the shop's billing anchor; see S5.
  4. Store — src/usage/metrics.ts (new) listUsageMetrics(appId?), createUsageMetric(input), updateUsageMetric(id, input), deleteUsageMetric(id), reorderUsageMetrics(ids). Validation: sum needs property; count clears it; assertAppInScope; name unique per app → 409.
  5. Routes — src/server/usage.ts (dashboard router from S1, behind requireAuth) GET /metrics, POST /metrics, PUT /metrics/:id, DELETE /metrics/:id, PUT /metrics/order. GET /metrics/preview?appId&eventName&method&property&window&shopId → { value, events: [last 20 matching rows] } — works on an unsaved form, like Mantle's right-hand panel. GET /properties?appId&eventName → distinct JSON keys seen in the last 500 events (json_each), for the "Property to sum" picker.
  6. Page — web/src/components/UsageMetrics.tsx (new) USAGE_METRICS: PageSpec (id: 'usage-metrics', kind: 'usage-metrics') as a child of CUSTOMERS beside "Usage events". List view: name, event, calculation ("Sum of property: usdOrderTotal" / "Count"), shown-on-customer toggle. Edit view: name, event name (select from eventNames), radio count/sum, property select (from /properties), format, show on customer page; right panel = preview with window select + customer search. Delete with a confirm.
  7. Seed helper — CLI partnerdex usage:seed-izigift --app ID creates the 9 metrics in Mantle's list (Total Orders = count; Total Revenue = sum usdOrderTotal; Upsell Revenue = sum usdUpsellRevenue; Gift Card / Store Credit Dollars Redeemed = sum usdGcDollarsRedeemed / usdScDollarsRedeemed; the four "Shop Currency" ones on the original* properties with show_on_customer = 0). Skips names that exist. Saves Henry nine forms.
