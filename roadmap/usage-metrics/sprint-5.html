Sprint 5 — Cross-customer usage reports

Not designed · repo: partnerdex

This sprint is not locked. It holds open questions, not a Build list. Write the Build list after S4 runs for a few weeks and Henry knows which question he asks most.

Candidate pieces

  • Leaderboard. Top merchants by a chosen metric and window. Reuses aggregateMetric() with GROUP BY shop_id.
  • Customers list column. One chosen usage metric as a sortable column in listCustomers() (src/customers/index.ts:215).
  • Metric over time. A usage:<metricId> series through the existing metric registry and metric_cache, so it gets the shared window controls for free.
  • Value ratio. Usage revenue ÷ MRR per merchant — "they made $3,118 on a $49 plan". Strong for churn-save calls and case studies.
  • Churn signal. Merchants still paying but with zero orders in 30 days → a Slack topic in src/notifications/topics.ts.
  • Property filters. The reserved usage_metrics.filters column ("only orders where originalCurrency = GBP").
